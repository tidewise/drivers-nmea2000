nmea2000
=============
NMEA2000 protocol support

This package contains both the NMEA2000 packet buffering logic (to build a
NMEA2000 message from separate CAN packages) and the definition of common PGNs.

The PGN structs and decoding logic is code-generated by the `codegen/` tool that
lives in the package. The information comes from the `pgns.xml`, which was taken
from the OpenSkipper project around 2020.

Whenever either the codegen tool or the pgns.xml file are updated, you need to
re-gen the corresponding files by running the following command from the root of
the package:

```
ruby -Icodegen/lib codegen/codegen pgns.xml src/
```
